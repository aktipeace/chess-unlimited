# Checklist pengujian mobile

Uji setidaknya pada lebar 320 px, 360 px, 390 px, dan 430 px.

- [ ] Tidak ada horizontal scrolling pada halaman Analysis, History, dan Settings.
- [ ] Seluruh papan terlihat tanpa pinch/zoom manual.
- [ ] Papan tetap persegi saat orientasi layar berubah.
- [ ] Tap untuk memilih bidak dan tujuan bekerja.
- [ ] Drag-and-drop bidak bekerja.
- [ ] Promosi bidak dapat dipilih.
- [ ] Undo, Reset, dan Flip mudah disentuh.
- [ ] Navigasi bawah tidak menutupi konten dan aman di area home-indicator.
- [ ] Stockfish berjalan dengan depth maksimal 15 dan MultiPV 1 pada ponsel.
- [ ] Memindahkan beberapa bidak berturut-turut tidak membuat analisis posisi lama terus berjalan.
- [ ] Mematikan analisis otomatis menghentikan pencarian otomatis.
- [ ] Desktop tetap menampilkan panel analisis di samping papan pada layar lebar.
